# emcombda

## Описание задачи

### Исходное задание
* **Источник:** T-Lab 2026. RecSys. Задание №1
* **Формулировка:** Исследовать, можно ли для ML-моделей в рекомендательных системах автоматизировать построение признаков (или заменить их обучаемыми представлениями) без потери качества рекомендаций? 

### Выбранное направление
* **Данные:** Датасет Yambda от Яндекса
* **Проблема:** Можно ли автоматизировать не только подбор и построение признаков, но и выбор их количества?
  
Данные эксперименты вдохновлены работой Кирилла Ярославовича Хрыльченко (НИУ ВШЭ) — Variable-Length Semantic IDs for Recommender Systems (2026), в которой идеи Emergent Communication используются для построения дискретных представлений объектов переменной длины. Автор предлагает модель, способную адаптивно выбирать длину идентификатора, сохраняя информацию об исходном эмбеддинге объекта.

В отличие от этой работы, мы предлагаем использовать в качестве исходной информации **для игры двух агентов** не готовые эмбеддинги объектов, а непосредственно историю взаимодействий пользователей с ними. Это позволяет исследовать возможность автоматического обнаружения поведенческих закономерностей, которые традиционно описываются вручную спроектированными признаками и их агрегациями. 

Исходная цель — проверить, могут ли взаимодействующие агенты самостоятельно сформировать компактный язык, определяющий не только содержание и способы кодирования таких закономерностей, но и необходимую сложность их представления, сохраняя при этом качество рекомендаций.
